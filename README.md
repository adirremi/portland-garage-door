# Portland Garage Door

Portland, Oregon garage door site.

## Pages

- `/` home
- `/services`
- `/about`
- `/locations`
- `/contact`
- `/locations/[street-slug]` one page per address, once listed

## Local

```bash
npm install
npm run dev
```

## Deploy

Live: https://portland-garage-door-vert.vercel.app

Set `NEXT_PUBLIC_SITE_URL` to that domain.
